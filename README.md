## Description
An advanced-level Python Web Scraper that automatically extracts 
quotes, authors and tags from quotes.toscrape.com across multiple 
pages and saves the structured data to JSON and CSV formats.
Built using BeautifulSoup4 and requests libraries.

## Features
- 🕷️ Scrapes 100 quotes across 10 pages automatically
- 👤 Extracts quote text, author name and tags
- 📄 Saves data to JSON format
- 📊 Saves data to CSV format
- 💾 Option to save to both formats simultaneously
- 🕐 Timestamps every scraped record
- 🔢 Auto-generates unique ID for each quote
- ✅ Handles pagination automatically
- ✅ Handles connection errors gracefully
- 👀 Preview scraped data before saving

## How to Run
Install required libraries:
```bash
pip install beautifulsoup4 requests
```
Then run:
```bash
python web_scraper.py
```
